# CampusPilot 智能出行管家 - 数据库设计说明

## 1. 引言
本文档旨在说明 CampusPilot 系统的数据库逻辑结构、物理结构及对象关系映射，确保数据的一致性、完整性与安全性。

## 2. 外部设计
系统采用 MySQL 8.0 数据库，字符集为 UTF-8mb4，命名规范统一采用下划线命名法（如 `t_user`）。

## 3. 结构设计

### 3.1 关系数据模型（表结构设计）

**表 1：用户表 (`t_user`)**
| 字段名 | 类型 | 主键/外键 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT | PK | 用户唯一标识，自增 |
| username | VARCHAR(50) | | 用户名，唯一 |
| password | VARCHAR(100)| | 密码（加密存储） |

**表 2：对话历史表 (`t_chat_history`)**
| 字段名 | 类型 | 主键/外键 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT | PK | 记录ID，自增 |
| user_id | BIGINT | FK | 关联用户ID |
| role | VARCHAR(20) | | 角色（user/assistant） |
| content | TEXT | | 对话内容 |
| create_time | DATETIME | | 创建时间 |

**表 3：待办事项表 (`t_todo`)**
| 字段名 | 类型 | 主键/外键 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT | PK | 待办ID，自增 |
| user_id | BIGINT | FK | 关联用户ID |
| task_name | VARCHAR(100) | | 任务名称 |
| status | TINYINT | | 0未完成，1已完成 |

**表 4：系统配置表 (`t_sys_config`)**
| 字段名 | 类型 | 主键/外键 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT | PK | 配置ID，自增 |
| config_key | VARCHAR(50) | | 配置键名（如 qwen_api_key） |
| config_value| VARCHAR(255) | | 配置值 |

## 4. 对象关系映射（ORM）
系统采用 MyBatis-Plus 作为 ORM 框架。
*   实体类 `User` 映射到表 `t_user`。
*   实体类 `ChatHistory` 映射到表 `t_chat_history`，并通过 `userId` 字段实现与用户表的关联。
*   实体类 `TodoItem` 映射到表 `t_todo`。
